## 1. Objetivo

Modal para **anexar comprovantes** a uma linha de despesa na página [Detalhe do ticket (02.1)](02.1-detalhe-ticket-kanban.md).

Abre ao clicar na coluna **Anexos** (ícone 📎 + contador) de uma despesa.

---

## 2. Acesso e permissões

| Perfil | Acesso |
|--------|--------|
| **Profissional help desk** (`gestec_help_desk:edit`) | Sim |
| Solicitante | Não |

**Tipo:** `Dialog` sobre `/gestec_help_desk/kanban/[ticketId]`.

**Gatilho:** clique em **Anexos** na linha da despesa.

---

## 3. Layout

```
┌─────────────────────────────────────────────┐
│  📎 Anexos                                  │
│  Despesa 1                                  │
│  2 x R$ 4.000,00 = R$ 8.000,00              │
├─────────────────────────────────────────────┤
│  [ 📤 Anexar documento ]                    │
│  PDF ou imagem, até 10 MB.                  │
├─────────────────────────────────────────────┤
│  ┌ - - - - - - - - - - - - - - - - - - - ┐ │
│  │ Nenhum comprovante anexado a esta     │ │
│  │ despesa.                              │ │
│  └ - - - - - - - - - - - - - - - - - - - ┘ │
└─────────────────────────────────────────────┘
```

### 3.1 Header

| Elemento | Conteúdo |
|----------|----------|
| Título | **Anexos** (ícone clipe) |
| Contexto | Nome da despesa + resumo `Qtd x Unit. = Total` |

### 3.2 Ações

| Elemento | Comportamento |
|----------|---------------|
| **Anexar documento** | Abre seletor de arquivo |
| Hint | *PDF ou imagem, até 10 MB.* |

### 3.3 Lista

| Estado | UI |
|--------|-----|
| Vazio | Área tracejada: *Nenhum comprovante anexado a esta despesa.* |
| Com arquivos | Lista nome + tamanho + excluir — **TBD** preview |

Contador na coluna **Anexos** da tabela atualiza após upload.

## 5. API

| Operação | Método | Endpoint |
|----------|--------|----------|
| Listar anexos | GET | `.../tickets/:ticketId/expenses/:expenseId/attachments` |
| Upload | POST | `.../attachments` (multipart) |
| Excluir | DELETE | `.../attachments/:attachmentId` |

**Permissão:** `gestec_help_desk:edit`
