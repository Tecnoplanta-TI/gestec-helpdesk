## 1. Objetivo

Tela de **configuração e administração** de uma integração HTTP/API — aberta ao clicar no nome na [lista (04)](04-integracoes.md) ou ao **+ Adicionar**.

Editor estilo **Postman/Zeev** para definir método, URL, corpo, autenticação, cabeçalhos, transformação e metadados. Permite **salvar**, **testar** a chamada e visualizar **alertas/diagnósticos** em tempo real.

---

## 2. Acesso e permissões

| Perfil | Acesso |
|--------|--------|
| **Profissional help desk** (`gestec_help_desk:edit`) | CRUD + testar |
| Solicitante | Não |

**Rotas:**

| Contexto | Rota |
|----------|------|
| Nova integração | `/gestec_help_desk/integracoes/nova` |
| Editar existente | `/gestec_help_desk/integracoes/[id]` |

**Breadcrumb:** `Início / Gestec Help Desk / Integrações / {nome ou Nova integração}`

---

## 3. Layout geral

```
┌─────────────────────────────────────────────────────────────────────────┐
│  {Nome da integração}              [ Voltar ] [ Salvar e testar ] [Salvar]│
├──────────────────────────────────────────────┬──────────────────────────┤
│  [POST ▼] [ https://...webhook URL        ] {} RESTful JSON             │
│  Parâmetros | Corpo | Autenticação | Cabeçalhos | Transformação | Config │
│  ┌────────────────────────────────────────┐ │  Alertas / diagnósticos   │
│  │  Conteúdo da aba ativa                 │ │  (painel direito)         │
│  └────────────────────────────────────────┘ │                           │
└──────────────────────────────────────────────┴──────────────────────────┘
```

### 3.1 Header

| Elemento | Comportamento |
|----------|---------------|
| Título | Nome da integração — ex.: **API - Enviar P1 ao Discord** (atualiza ao salvar aba Configurações) |
| **Voltar** | Outline → `/gestec_help_desk/integracoes` |
| **Salvar e testar** | Outline + ícone ▶ — persiste e dispara requisição de teste §7 |
| **Salvar** | Primary verde — persiste configuração |

## 5. Abas de configuração

Navegação `Tabs` horizontal. Conteúdo abaixo da barra de requisição.

### 5.1 Parâmetros

Query string da requisição — pares **Chave / Valor** (mesmo padrão Cabeçalhos).

| Elemento | Descrição |
|----------|-----------|
| Linhas | Chave + Valor editáveis |
| **+ Adicionar linha** | Nova linha vazia |

Suporte a variáveis template `{ticket.*}` nos valores — **TBD**.

### 5.2 Corpo

Editor do **body** da requisição (JSON).

| Elemento | Descrição |
|----------|-----------|
| Editor | `Textarea` ou editor JSON com syntax highlight |
| Variáveis | Placeholders substituídos em runtime — §6 |

**Exemplo (Figma — Discord P1):**
```json
{
  "content": "🚨 P1 — {ticket.ticketNumber}\nAbertura: {ticket.openedAt}\nSolicitante: {ticket.requester.name}\nTipo: {ticket.type}\n{ticket.title}",
  "username": "gestec - help desk"
}
```

## 9. Dados e API

| Operação | Método | Endpoint |
|----------|--------|----------|
| Obter config | GET | `/api/v1/gestec-help-desk/integrations/:id` |
| Salvar | PUT / POST | `/api/v1/gestec-help-desk/integrations/:id` |
| Testar | POST | `/api/v1/gestec-help-desk/integrations/:id/test` |

**Payload (exemplo):**
```json
{
  "name": "API - Enviar P1 ao Discord",
  "type": "restful_json",
  "method": "POST",
  "url": "https://discord.com/api/webhooks/...",
  "parameters": [],
  "body": "{ \"content\": \"...\" }",
  "auth": { "type": "bearer", "token": "..." },
  "headers": [
    { "key": "User-Agent", "value": "gestec-help-desk/1.0" },
    { "key": "Content-Type", "value": "application/json" }
  ],
  "transformation": {
    "filterOrLoop": "",
    "value": "",
    "text": "",
    "orderBy": "",
    "accessoryFields": []
  }
}
```

**Teste:** backend monta request com variáveis de **ticket mock** ou ticket informado — **TBD**.
