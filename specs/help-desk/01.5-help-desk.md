## 1. Objetivo

Modal para o **solicitante** revisar o trabalho concluído pelo help desk após **Enviar para aprovação** ([01.4](01.4-help-desk.md)).

O usuário confere apontamentos, valores, o que foi realizado e decide:

| Ação | Resultado |
|------|-----------|
| **Aprovar conclusão** | Segue para [Avaliação do serviço (01.6)](01.6-help-desk.md) |
| **Devolver ao atendente** | Ticket retorna ao atendimento; justificativa **obrigatória** |

Status do ticket na lista ([01](01-help-desk.md)): **Aprovar apontamentos** / aguardando aprovação — **TBD** label exato.

## 2. Acesso e permissões

| Perfil | Acesso |
|--------|--------|
| **Solicitante** (dono do ticket) | Modal completo — decisão |
| **Profissional help desk** | Somente leitura ou sem acesso — **TBD** |
| Outros usuários | Não |

**Tipo:** `Dialog` largo + scroll — rota `/gestec_help_desk`.

**Gatilho:** notificação + clique no ticket na lista; ou item **Fila de aprovação** — **TBD**.

**Permissão:** `gestec_help_desk:view` (solicitante com acesso ao próprio ticket)

## 3. Layout

Mesma estrutura base do [01.4](01.4-help-desk.md): coluna esquerda (scroll) + sidebar **Cobrança** + **Decisão**.

### 3.1 Header

| Elemento | Conteúdo |
|----------|----------|
| Título | `Aprovar conclusão · {numeroTicket}` |
| Subtítulo | `{tituloTicket}` |
| **← Fila de aprovação** | Fecha modal; volta à lista |

### 3.2 Coluna esquerda (readonly — resumo do atendimento)

| Seção | Conteúdo |
|-------|----------|
| **Solicitante** | Data abertura, nome |
| **Ticket** | Número, centro de custo, tipo, prioridade, nível, grupo, descrição original |
| **Responsável** | Atendente, prazo, responsável adicional (— se nenhum) |
| **Lacre de segurança** | Houve troca do lacre? |
| **O que foi realizado** | Texto registrado pelo help desk |
| **Apontamentos** | Tabela: Responsável, Data, Descrição, Duração |
| **Tabela de cobrança** | Materiais/serviços ou *Nenhum material/serviço lançado* |
| **Equipamentos entregues** | Lista ou *Nenhum equipamento* |
| **Mensagens** | Histórico + campo *Digite uma mensagem…* + **Adicionar** — **TBD** se solicitante pode enviar aqui |

### 3.3 Sidebar — Cobrança

| Linha | Exemplo |
|-------|---------|
| Preço/hora | R$ 105,00 |
| Valor atendimento | R$ 325,50 |
| Materiais | R$ 0,00 |
| **Valor final** | **R$ 325,50** |

### 3.4 Sidebar — Decisão

| Campo | Tipo | Obrigatório |
|-------|------|-------------|
| **Justificativa (obrigatória se recusar)** | `Textarea` | Sim apenas ao **Devolver** |

| Botão | Cor | Ação |
|-------|-----|------|
| **Aprovar conclusão** | Verde ✓ | Abre modal [01.6](01.6-help-desk.md) |
| **Devolver ao atendente** | Vermelho/rosa ✗ | Retorna ticket; exige justificativa |

#### Devolver ao atendente

1. Valida justificativa preenchida.
2. Status → retorno ao atendimento (ex.: reabre [01.4](01.4-help-desk.md)).
3. Notifica responsável/help desk — **TBD**.
4. Toast; fecha modal.

#### Aprovar conclusão

1. Registra aceite do solicitante sobre valores e entregáveis.
2. **Abre modal 01.6** (Avaliação NPS) — não encerra ticket ainda.
3. Ticket permanece em transição até enviar avaliação — **TBD**.
