## 1. Objetivo

Página de **visualização completa** do chamado, aberta ao clicar em um card no [Kanban (02)](02-kanban.md).

Permite ao help desk:

1. Consultar todos os metadados do ticket.
2. **Iniciar cronômetro** de atendimento.
3. **Avançar ou voltar etapas** do workflow (transição de etapa).
4. Ver **histórico de workflow**.
5. Registrar **despesas** vinculadas ao ticket (com anexos — [02.1.1](02.1.1-anexos-despesa.md)).

## 5. Integrações / API

| Operação | Método | Endpoint |
|----------|--------|----------|
| Detalhe ticket | GET | `/api/v1/gestec-help-desk/tickets/:id` |
| Transição etapa | POST | `.../tickets/:id/workflow/transition` |
| Histórico workflow | GET | `.../tickets/:id/workflow/history` |
| Iniciar timer | POST | `.../timer/start` |
| Despesas list/create/delete | GET/POST/DELETE | `.../tickets/:id/expenses` |

**Payload transição:**
```json
{ "targetStageId": "uuid", "direction": "forward" }
```
