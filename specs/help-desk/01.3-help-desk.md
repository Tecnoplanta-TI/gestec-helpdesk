## 1. Objetivo

Modal exibido ao help desk quando o ticket está em status **Contato inicial** — etapa após triagem aprovada ([01.2](01.2-help-desk.md)).

O responsável (ou profissional help desk) **visualiza os dados da solicitação**, confere classificação e clica em **Iniciar contato inicial** para registrar o **primeiro atendimento** do chamado.

Disponível ao clicar no ticket na lista ([01](01-help-desk.md)) com status **Contato inicial**.

---

**Gatilho:** clique no ticket com status **Contato inicial** na tabela (01).

## 5. Ações do usuário

### 5.1 Iniciar contato inicial

| Passo | Comportamento |
|-------|---------------|
| 1 | Valida campos obrigatórios (centro de custo, prioridade, nível) |
| 2 | POST API — registra timestamp de início do contato |
| 3 | Atualiza status do ticket → próximo do fluxo — **TBD** (ex.: Em atendimento) |
| 4 | **Inicia cronômetro** de atendimento na sidebar ([01](01-help-desk.md) §5) vinculado ao ticket |
| 5 | Toast sucesso; **abre modal [01.4](01.4-help-desk.md)** ou mantém fluxo contínuo — **TBD** UX |
| 6 | Refresh lista na página 01 |

> O cronômetro passa a ficar visível para o profissional help desk com título do ticket, badges **Ticket** / **Rodando**, controles pausar/parar e **Abrir ticket**.

### 5.2 Ver detalhe completo

Abre modal/página com todos os campos do ticket (descrição, anexos, histórico) — **spec futura**.

### 5.3 Fila de atendimento

Fecha modal sem alterar ticket; retorna à lista.

## 6. Integrações / API

| Operação | Método | Endpoint | Quando |
|----------|--------|----------|--------|
| Detalhe ticket | GET | `/api/v1/gestec-help-desk/tickets/:id` | Abrir modal |
| Iniciar contato | POST | `/api/v1/gestec-help-desk/tickets/:id/initial-contact/start` | Botão verde |
| Timer start | POST | `/api/v1/gestec-help-desk/timer/start` | Após iniciar contato — **TBD** unificar |

**Payload iniciar contato (exemplo):**
```json
{
  "costCenterId": "47",
  "priority": "p2",
  "level": "n1"
}
```

**Response:** ticket atualizado + sessão de timer criada.

**Permissão API:** `gestec_help_desk:edit`

## 7. Regras de negócio

1. Modal exibido apenas em status **Contato inicial**.
2. Ticket chega aqui após **Aprovar e encaminhar** na triagem ([01.2](01.2-help-desk.md)).
3. Responsável assignado na triagem é quem deve iniciar — **TBD** restringir a outros perfis.
4. **Iniciar contato inicial** é irreversível nesta etapa — **TBD** confirmação modal.
5. Ajustes de prioridade/nível/centro de custo persistidos ao iniciar.
6. Cronômetro: um ativo por profissional; vinculado ao ticket iniciado.
