## 1. Objetivo

Modal filho que lista o **software detectado na última coleta** de uma estação, com filtro por categoria e busca textual.

Abre ao clicar em **Aplicativos** no modal [01.1](01.1-gestec-desk.md). Um único modal alterna entre três modos via dropdown:

| Modo (Figma) | Tipo API |
|--------------|----------|
| **Filtragem de aplicativos** | `aplicativos` |
| **Filtragem de .NET Runtimes** | `dotnet` |
| **Filtragem de atualizações** | `atualizacoes` |

Permanece em `/gestec-desk` — modal empilhado sobre o 01.1.

## 4. Modos de filtragem (dropdown)

O `Select` controla o parâmetro `type` da API. Ao trocar o tipo, recarregar lista automaticamente (resetar busca opcional — manter busca é aceitável).

| Label (UI) | `type` API | Fonte raw |
|------------|------------|-----------|
| **Aplicativos** | `aplicativos` | `Software.Aplicativos[]` |
| **.NET Runtimes** | `dotnet` | `Software.DotNetRuntimes[]` |
| **Atualizações** | `atualizacoes` | `Software.Atualizacoes[]` |

> Panel também expõe `uwp` e `drivers` — **fora do escopo Figma**; não incluir no dropdown desta spec.

### 4.1 Filtragem de aplicativos (`aplicativos`)

Cada item exibe:

| Campo (UI) | Campo raw | Formatação |
|------------|-----------|------------|
| **Nome** | `Nome` | Texto |
| **Versão** | `Versao` | Texto |
| **Fabricante** | `Fabricante` | Texto |
| **Instalado em** | `InstaladoEm` | pt-BR (`YYYYMMDD` → `dd/mm/aaaa`) |

### 4.2 Filtragem de .NET Runtimes (`dotnet`)

Cada item exibe:

| Campo (UI) | Campo raw | Formatação |
|------------|-----------|------------|
| **Nome** | `Nome` | ex.: `Microsoft.NETCore.App` |
| **Versão** | `Versao` | Texto |
| **Fabricante** | `Fabricante` | Texto; `-` se ausente |
| **Instalado em** | `InstaladoEm` | pt-BR; `-` se ausente |

> Dados reais de .NET Runtimes costumam trazer apenas Nome e Versão — exibir `-` nos demais.

### 4.3 Filtragem de atualizações (`atualizacoes`)

Cada item exibe:

| Campo (UI) | Campo raw | Formatação |
|------------|-----------|------------|
| **Kb** | `Kb` | ex.: `KB5066130` |
| **Título** | `Titulo` | Texto |
| **Instalado em** | `InstaladoEm` | pt-BR (aceitar `M/D/YYYY` e ISO) |

Layout de **Atualizações** no Figma: 3 campos por card (sem Versão/Fabricante).

## 5. Toolbar e ações

| Ação | Gatilho | Comportamento |
|------|---------|---------------|
| Trocar tipo | `Select` | GET software com novo `type`; atualiza lista e Total |
| Filtrar | Input + Enter ou debounce | GET com `search` |
| Carregar | Botão | Refaz GET com `type` + `search` atuais (igual panel) |
| Fechar | Fechar / X / ESC | Fecha modal; volta ao 01.1 |

### 5.1 Busca

- Placeholder: **"Filtrar software"**
- Filtra no **backend** via query `search` (panel: match em qualquer campo do item, case insensitive)
- Ao limpar busca, restaurar lista completa do tipo selecionado

### 5.2 Paginação

- Carregar com `page=1` e `pageSize=100` (padrão panel)
- Se `total > pageSize`: scroll infinito ou paginação — **TBD**; mínimo aceitável: exibir primeiros 100 + aviso

### 5.3 Contador

Linha **"Total: {n}"** acima da lista, onde `n` = `response.total` (após filtro).

## 6. Integrações / API

| Operação | Método | Endpoint | Quando |
|----------|--------|----------|--------|
| Software por tipo | GET | `/api/v1/gestec-desk/stations/:hostname/software` | Abrir modal, trocar tipo, buscar, Carregar |

**Query params:**

| Param | Valores | Default |
|-------|---------|---------|
| `type` | `aplicativos`, `dotnet`, `atualizacoes` | `aplicativos` |
| `page` | número | `1` |
| `pageSize` | 1–200 | `100` |
| `search` | string | `""` |

**Permissão:** `gestec_desk:view`

**Response:**
```json
{
  "stationId": "DESKTOP-A",
  "type": "aplicativos",
  "page": 1,
  "pageSize": 100,
  "total": 42,
  "items": [
    { "Nome": "AnyDesk", "Versao": "1.2.3", "Fabricante": "AnyDesk", "InstaladoEm": "20250122" }
  ]
}
```

**Erros:**
- `404` — estação sem inventário: toast + fechar modal ou empty state
- `403` — acesso negado

**Fonte dos dados:** último snapshot (`stationCurrent`) — mesma base do modal 01.1, não histórico antigo.

## 7. Regras de negócio

1. Modal **somente leitura**.
2. Sempre exibe software da **última coleta** da estação.
3. Subtítulo usa `hostname` repassado do 01.1.
4. Lista vazia: *"Nenhum item encontrado."* (ou equivalente por tipo).
5. Fechar 01.1.1 volta ao 01.1; fechar 01.1 fecha também 01.1.1.
6. Um modal de aplicativos por vez.

## 8. Estados da tela

| Estado | UI |
|--------|-----|
| Carregando | Skeleton na lista |
| Sucesso | Total + cards preenchidos |
| Lista vazia | Total: 0 + mensagem |
| Erro API | Toast + retry |
| Busca sem match | Total: 0 |

**Estado inicial:** tipo **Aplicativos**, busca vazia, lista carregada ao abrir.
