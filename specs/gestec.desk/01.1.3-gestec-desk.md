## 1. Objetivo

Página de **inspeção detalhada** de uma coleta de inventário específica, com todos os dados coletados pelo agente **gestec.desk**.

Abre ao clicar em **Abrir visualização** no modal [01.1.2 — Histórico](01.1.2-gestec-desk.md). Organiza o snapshot em **seções colapsáveis** (Resumo, Sistema, Hardware, etc.) com busca, expandir/recolher global e exportação JSON.

É **uma única página com scroll** — os prints do Figma são trechos da mesma tela.

## 4. Seções e origem dos dados

Dados de `GET /api/v1/gestec-desk/stations/:hostname/inventories/:inventoryId`.

O payload contém o inventário **normalizado** + objeto `raw` original do Cosmos (coleta do gestec.desk).

### 4.1 Mapeamento seção → fonte

| Seção (UI — português) | Fonte de dados | Colunas |
|------------------------|----------------|---------|
| **Resumo** | `{ id, stationId, collectedAt, currentUser }` do payload | CAMPO \| VALOR |
| **Sistema** | `raw.System` | CAMPO \| VALOR |
| **Hardware** | `raw.Hardware` | CAMPO \| VALOR |
| **Segurança** | `raw.Security` | CAMPO \| VALOR |
| **Campos Adicionais** | Demais chaves de `raw` exceto `System`, `Hardware`, `Security`, `Software` | CAMPO \| VALOR |
| **Software - Aplicativos** | `raw.Software.Aplicativos[]` | Nome \| Versão \| Fabricante \| Instalado em |

### 4.2 Achamento de campos (seções CAMPO/VALOR)

Objetos aninhados do `raw` são **achatados** com notação ponto — igual ao panel:

```
Hardware.Cpu.Nome → "Intel Core i7"
Hardware.Memoria.PorSlot[0].CapacidadeGB → 8
```

Implementar utilitário `flattenObject()` (reutilizar lógica de `buildInventoryViewerHtml`).

### 4.3 Software - Aplicativos

Lista de apps instalados coletados pelo agente. Tabela dedicada (4 colunas) — mais legível que achatamento:

| Coluna | Campo raw |
|--------|-----------|
| Nome | `app.Nome` |
| Versão | `app.Versao` |
| Fabricante | `app.Fabricante` |
| Instalado em | `app.InstaladoEm` → formatar pt-BR (suporta YYYYMMDD) |

### 4.4 Formatação de valores

| Tipo | Tratamento |
|------|------------|
| null / undefined | `-` |
| Objeto / array | JSON stringificado ou representação legível (`<code>`) |
| Datas | pt-BR |

**Estado inicial:** todas as seções **expandidas** (botão mostra **Recolher**).

## 5. Toolbar e ações

| Ação | Gatilho | Comportamento |
|------|---------|---------------|
| Buscar | Input search | Filtra **linhas** em todas as seções (case insensitive, campo + valor) |
| Expandir tudo | Botão | Abre todas as seções; toggles → **Recolher** |
| Recolher tudo | Botão | Fecha todas; toggles → **Espalhar** |
| Exportar JSON | Botão primary | Download `inventario_{timestamp}.json` com objeto **`raw`** completo |
| Toggle seção | Recolher/Espalhar | Esconde/mostra tabela da seção |
| Voltar | Breadcrumb "Gestec Desk" | `/gestec-desk` |

### 5.1 Toggle Recolher / Espalhar

| Estado da seção | Texto do botão |
|-----------------|----------------|
| Tabela **visível** | **Recolher** |
| Tabela **oculta** | **Espalhar** |

> Panel usa "Expandir"; no Gestec usar **"Espalhar"** conforme instrução.

Apenas o **corpo** (tabela) colapsa — header do card (título + botão) permanece visível.

### 5.2 Busca

Filtra linhas com classe/atributo `data-search` contendo termo em campo ou valor. Linhas ocultas permanecem ocultas mesmo ao espalhar seção.

## 6. Integrações / API

| Operação | Método | Endpoint | Quando |
|----------|--------|----------|--------|
| Inventário completo | GET | `/api/v1/gestec-desk/stations/:hostname/inventories/:inventoryId` | Ao carregar página |

**Permissão:** `gestec_desk:view`

**Response esperada:**
```json
{
  "id": "uuid",
  "stationId": "DESKTOP-A",
  "collectedAt": "ISO8601",
  "currentUser": "string",
  "raw": {
    "System": {},
    "Hardware": {},
    "Security": {},
    "Software": { "Aplicativos": [] }
  }
}
```

**Erros:**
- `404` → mensagem + link voltar para `/gestec-desk`
- `403` → acesso negado

**Validação:** `inventoryId` deve pertencer ao `hostname` da URL.

## 7. Regras de negócio

1. Página **somente leitura**.
2. Exibe snapshot **da coleta clicada** — não o inventário "atual" genérico.
3. Seção vazia: exibir card com *"Nenhum dado nesta seção."*
4. Software sem apps: *"Nenhum aplicativo encontrado."*
5. Export JSON = objeto `raw` integral (dado bruto Cosmos/gestec.desk).
6. Toolbar pode ser **sticky** no topo durante scroll — recomendado (panel behavior).
