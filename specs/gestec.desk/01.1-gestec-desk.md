## 1. Objetivo

Modal sobre a página principal ([01](01-gestec-desk.md)) que exibe o **inventário atual** (último snapshot) de uma estação clicada na tabela de estações.

Somente leitura. Oferece atalhos para **Aplicativos** e **Histórico** — interações detalhadas em specs filhas.

---

## 2. Acesso e permissões

| Perfil | Pode acessar? |
|--------|---------------|
| `gestec_desk:view` | Sim |
| Sem permissão | Modal não abre |

**Tipo:** **Modal (Dialog)** — **não** é rota separada. Permanece em `/gestec-desk`.

**Permissão:** `gestec_desk:view`

**Gatilho:** clique na **linha** da tabela de estações (spec 01).

> Clique no **checkbox** apenas seleciona para auditoria — **não** abre o modal.

**Implementação:**
```tsx
<Dialog open={open} onOpenChange={setOpen}>
  {/* conteúdo */}
</Dialog>
```

Página pai continua protegida por:
```tsx
<ProtectedRoute module={Modules.GestecDesk} action={Actions.View}>
```

## 4. Campos exibidos

Dados do **último inventário** via `GET /api/v1/gestec-desk/stations/:hostname/current`.

Layout conforme Figma (coluna esquerda | direita):

| Label (UI) | Campo API | Formatação |
|------------|-----------|------------|
| **ID** | `id` | UUID/registro |
| **USUARIO** | `system.currentUser` | Texto; `-` se vazio |
| **WINDOWS** | `system.windowsVersion` | Texto |
| **UPTIMEHORAS** | `system.uptimeHours` | Número (+ "h" opcional) |
| **RAM (GB)** | `hardware.memory` | Total + slots — ex.: `16 (2x8GB)` (igual panel) |
| **DISCOS** | `hardware.disks[]` | Modelo, usado/total, % — separados por `\|` |
| **BIOS SERIAL** | `system.biosSerial` | Texto |
| **CPU** | `hardware.cpu.name` | Texto |
| **GPU** | `hardware.gpus[]` | Nome(s); VRAM se houver; `\|` se múltiplas |
| **IPS** | `network.currentIpv4[]` | Separados por vírgula |
| **PLACA MÃE** | `motherboardVendor` + `motherboardModel` | `"Fabricante Modelo"` |
| **COLETADO EM** | `collectedAt` | `dd/mm/aaaa, hh:mm` (pt-BR) |
| **DOMINIO/WORKGROUP** | `system.domainOrWorkgroup` | Texto |
| **ARQUITETURA** | `system.architecture` | ex.: `64-bit` |

Valores ausentes: `-`.

## 5. Ações do usuário

| Ação | Gatilho | Resultado | Spec filha |
|------|---------|-----------|------------|
| Abrir modal | Clique na linha (spec 01) | Dialog abre; GET current | — |
| Fechar | Fechar / X / ESC | Dialog fecha; permanece em `/gestec-desk` | — |
| Aplicativos | Botão "Aplicativos" | Modal filho empilhado | [01.1.1](01.1.1-gestec-desk.md) |
| Histórico | Botão "Histórico" | Modal filho empilhado | [01.1.2](01.1.2-gestec-desk.md) |

### 5.1 Checkbox vs. linha

| Clique em | Comportamento |
|-----------|---------------|
| Checkbox | Toggle seleção auditoria em massa |
| Restante da linha | Abre este modal |

Implementar `onClick` na linha e `stopPropagation` no checkbox.

### 5.2 Contexto passado aos filhos

Ao abrir Aplicativos ou Histórico, repassar:
- `hostname` (obrigatório)
- Dados já carregados quando aplicável

Modais filhos empilham **sobre** este Dialog. Fechar o pai fecha os filhos.

---

## 6. Regras de negócio

1. Exibir sempre o **snapshot mais recente** (`stationCurrent`) — não histórico completo.
2. Modal **somente leitura**.
3. Um modal de detalhe por vez.
4. **404** ou estação sem inventário: toast de erro; modal não abre ou exibe empty state.
5. Ao fechar, limpar estado local (`selectedHostname`, dados cached) — opcional manter para reabrir mesma estação.

## 7. Integrações / API

| Operação | Método | Endpoint | Quando |
|----------|--------|----------|--------|
| Inventário atual | GET | `/api/v1/gestec-desk/stations/:hostname/current` | Ao abrir modal |

**Permissão API:** `gestec_desk:view`

**Response (campos relevantes):**
```json
{
  "id": "string",
  "stationId": "string",
  "collectedAt": "ISO8601",
  "system": {
    "currentUser": "string",
    "windowsVersion": "string",
    "architecture": "string",
    "uptimeHours": 0,
    "domainOrWorkgroup": "string",
    "biosSerial": "string",
    "motherboardVendor": "string",
    "motherboardModel": "string"
  },
  "hardware": {
    "cpu": { "name": "string" },
    "memory": { "totalGB": 0, "bySlot": [] },
    "disks": [],
    "gpus": [{ "name": "string", "vramMB": 0 }]
  },
  "network": {
    "currentIpv4": ["string"]
  }
}
```

**Software (Aplicativos):** `GET .../stations/:hostname/software?type=&page=&pageSize=&search=` — ver [01.1.1](01.1.1-gestec-desk.md)
