## 1. Objetivo

Modal filho que exibe o **histórico de coletas de inventário** de uma estação específica, organizado por **calendário mensal**.

Abre ao clicar em **Histórico** no modal [01.1](01.1-gestec-desk.md). O usuário identifica dias com inventário (●), seleciona uma data e vê a lista de coletas daquele dia, com opção de **Abrir visualização** (spec [01.1.3](01.1.3-gestec-desk.md)).

Permanece na página `/gestec-desk` — modal empilhado sobre o 01.1.

## 4. Calendário

### 4.1 Comportamento

| Regra | Detalhe |
|-------|---------|
| Mês inicial | **Mês atual** ao abrir |
| Navegação | ← → recarrega destaques do mês |
| Dias com inventário | Exibem **●** preto abaixo do número |
| Dias sem inventário | Sem ●; tom neutro |
| Dias de outro mês (padding) | Cinza claro; não clicáveis |
| Clique em dia **com** ● | Marca seleção + carrega tabela |
| Clique em dia **sem** inventário | Sem ação — **TBD:** toast opcional |

### 4.2 API do calendário

`GET /api/v1/gestec-desk/stations/:hostname/inventories/dates?month=YYYY-MM`

**Response:**
```json
{
  "hostname": "DESKTOP-A",
  "month": "2026-04",
  "items": [
    { "date": "2026-04-04", "count": 2 },
    { "date": "2026-04-25", "count": 4 }
  ]
}
```

`count` = quantidade de coletas naquele dia (usar no tooltip: *"4 inventário(s)"*).

## 5. Tabela de coletas (após selecionar dia)

### 5.1 Exibição

| Elemento | Conteúdo |
|----------|----------|
| Label | `Data selecionada: DD/MM/AAAA` |
| Tabela | Abaixo do calendário, dentro do mesmo modal |

### 5.2 Colunas

| Coluna | Campo | Formato |
|--------|-------|---------|
| COLETADO EM | `item.collectedAt` | `dd/mm/aaaa, hh:mm:ss` (pt-BR) |
| USUÁRIO | `item.currentUser` | Texto; `-` se vazio |
| Ação | — | Botão **Abrir visualização** |

### 5.3 API da tabela

`GET /api/v1/gestec-desk/stations/:hostname/inventories?date=YYYY-MM-DD`

**Response:**
```json
{
  "hostname": "DESKTOP-A",
  "date": "2026-04-25",
  "items": [
    { "id": "uuid", "collectedAt": "ISO8601", "currentUser": "string" }
  ]
}
```

- Múltiplas coletas no **mesmo dia** → múltiplas linhas
- Ordenação sugerida: `collectedAt` **DESC** (mais recente primeiro)

### 5.4 Abrir visualização

| Ação | Resultado |
|------|-----------|
| Clique em "Abrir visualização" | Navega para [01.1.3](01.1.3-gestec-desk.md) |

Rota prevista: `/gestec-desk/inventario/:hostname/:inventoryId`

> Ao navegar, modais 01.1 e 01.1.2 são desmontados (comportamento Next.js).

## 6. Ações do usuário

| Ação | Gatilho | Resultado |
|------|---------|-----------|
| Abrir | Histórico (01.1) | Modal abre; calendário mês atual |
| Fechar | Fechar / X / ESC | Fecha 01.1.2; **01.1 permanece aberto** |
| Trocar mês | ← → | Recarrega ●; limpa seleção e tabela |
| Selecionar dia | Clique em dia com ● | Destaque + label + GET coletas |
| Abrir visualização | Botão na linha | `router.push` → 01.1.3 |

---

## 7. Regras de negócio

1. Histórico é **por estação** — `hostname` fixo (contexto do 01.1).
2. Não permite trocar estação dentro deste modal.
3. Fechar 01.1.2 **não** fecha 01.1.
4. Fechar 01.1 fecha 01.1.2 em cascata.
5. Trocar mês limpa `selectedDate` e esvazia tabela.
6. Rodapé fixo: *"Datas em destaque possuem inventário. Clique para listar as coletas."*

## 8. Estados

| Estado | UI |
|--------|-----|

| Mês sem inventário | Calendário + *"Nenhuma data com inventário neste mês."* |

| Dia com coletas | Label + tabela preenchida |
| Dia sem coletas (edge) | *"Nenhum inventário encontrado para a data."* |
